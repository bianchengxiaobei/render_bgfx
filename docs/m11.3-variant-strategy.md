# M11.3 Variant Strategy Evaluation

日期：2026-11-15

## 结论

M11.3 完成评估，决定 **不实现 4 类 light category 编译期变体，也不实现 HDRP 的 29 个 Lit feature variants**；保留 M10/M11 的 **tileFeatureFlags + runtime category gating**。新增仅用于评估的 `--no-light-list-feature-flags` 诊断开关，默认仍开启。

- 运行时 gating 关闭后，D3D11/Vulkan、forward/deferred、buffer/texture/CPU 全部 **0 diff**，说明当前 gating 是纯跳过优化，不改变语义。
- 1080p 300 帧 full-post stress 中，D3D11 gating on 26.491 ms / 37.7 fps，off 27.762 ms / 36.0 fps，gating 约省 **1.27 ms**；Vulkan 在噪声范围内。保留 gating 有实际收益。
- 4 类编译期 category variants 在当前渲染器上没有对应的 per-tile program dispatch，无法替代 per-pixel gating；只会把 forward variant 数和 O3 构建成本约放大 4 倍。29 个 Lit variants 依赖当前项目没有的 SSS/transmission/anisotropy/clearcoat/iridescence 材质，不在 M11 伪造。

## HDRP 参考

- `Runtime/Material/Lit/Lit.hlsl:98-142`：`kFeatureVariantFlags[29]`。
- `Runtime/Material/Lit/Lit.hlsl:145-170`：`FeatureFlagsToTileVariant` / `TileVariantToFeatureFlags`。
- `Runtime/Lighting/LightLoop/LightLoop.cs.hlsl:63-67`：`NUM_FEATURE_VARIANTS (29)`、material/light feature mask。
- `Runtime/Lighting/LightLoop/builddispatchindirect.compute:41`：按 tile feature flags 生成每个 variant 的 indirect dispatch。

HDRP 的 29 个变体是 **材质特性 × 灯光特性** 的组合：

- 材质族：Standard、SSS/Transmission、Anisotropy、Clear Coat、Iridescence。
- 灯光组合：precomputed（SKY/ENV/SSREFLECTION）、directional+punctual、directional+area、directional+env/SSR、opaque all-flags 等。
- 这些变体由 **per-tile indirect dispatch** 选择，不是单一 view 级 shader 开关。

## 当前 HBG 与 HDRP 的差异

| 项目 | HDRP | 当前 HBG |
|---|---|---|
| 材质变体 | 29 个 feature combination，含 5 类材质族 | **16 个 opaque material mask**：normal/mask/alpha clip/double-sided 的 4 bit 组合；透明单独 pass |
| 灯光分类 | 编译期 variant + per-tile indirect dispatch | `tileFeatureFlags` 嵌入 FPTL/big-tile/cluster，shader 在 `light_loop.sc:252-323` 按 directional/punctual/area 运行时跳过 |
| variant 选择粒度 | per tile | 全屏 forward/deferred shader 同一 program，per pixel 读 tile flags |
| SSS/transmission/anisotropy/clearcoat/iridescence | 有材质实现 | 无材质实现 |
| cookie/IES/area | 独立 cookie atlas/feature flags | 已由 light data/cookie atlas 运行时处理 |

## 评估开关

新增：

- `PipelineSettings::supportLightListFeatureFlags`，默认 `true`。
- `--light-list-feature-flags` / `--no-light-list-feature-flags`。
- JSON `supportLightListFeatureFlags`。
- diagnostics `light_list_feature_flags`。

关闭时 `u_pass_lightListParams2.z = 0`，shader 不读 tile flags，所有 category 都进入循环；空 category 的 count 为 0，因此输出应与开启时完全一致。该开关只用于验证 gating 语义和性能，不是产品回退选项。

## 0 diff 验证

1280×720，`frames=3`：

- area16、spot、point100 × D3D11/Vulkan × forward/deferred = 12 组，gating on/off 全部 **0 diff**。
- area16 × D3D11/Vulkan × forward/deferred × texture path/CPU path = 8 组，gating on/off 全部 **0 diff**。
- 所有 20 组均保持原图像不变；gating 关闭只增加空 list 循环。

## 性能记录

场景：`m96_stress.gltf`，1920×1080，300 帧，full post（`config/postprocess_quality.json`），cap64；场景有 122 个候选灯，日志显示 `light_list_truncated=59`。

| Backend | gating on | gating off | 差异 |
|---|---:|---:|---:|
| D3D11 | 26.491 ms / 37.7 fps | 27.762 ms / 36.0 fps | on 快 1.27 ms（约 4.8%） |
| Vulkan | 23.189 ms / 43.1 fps | 22.247 ms / 44.9 fps | 噪声/CPU 波动，无稳定收益 |

结论：**保留 runtime gating**。关闭 gating 不会带来质量收益，反而在 D3D11 上增加约 1.27 ms。

## 构建成本评估

当前 manifest **510** 个 binary；forward 有 16 个 material mask × 2 条 light-list 存储路径（texture/buffer）× 2 后端 = **64** 个 fragment binary。若增加 4 个 view-wide category variants：

- forward binary 约 64 → 256，manifest 约 510 → 702。
- O3 forward 构建约放大 4 倍；并且 view 同时包含 directional+punctual+area 时，4 个 view-wide variant 仍无法减少 per-tile 分支，收益小于 runtime gating。
- HDRP 的 29 是 per-tile 组合；当前没有 `builddispatchindirect` 式的 tile program 选择，不能直接照搬。

## 最终决策

1. **保留** `tileFeatureFlags` + runtime category gating；默认开启。
2. **否决** 4 类编译期 category variants：无可测量的额外收益，构建成本高，且与当前全屏 program 架构不匹配。
3. **否决** 29 个 Lit feature variants：当前材质没有对应 feature；等 M12 材质特性落地后再开。
4. 29 variants 差异报告完成；M11.3 不再阻塞 M11.4 性能工作。
