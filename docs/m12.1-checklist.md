# hdrp-bgfx M12.1 Temporal Screen-Space Lighting 清单

> 状态：**SSAO + SSR + SSGI temporal、raw/history debug、真实 resize/scale reset、SSR/SSGI Y 翻转修复已完成**（2026-11-17）；A01 仍未关闭，M11.5 1080p full-post >60 fps 门禁未过（见 3.4）。
> 目标：按 A01 逐项落地历史缓冲、重投影、深度/法线拒绝和 temporal 合成；temporal off 必须保持当前基线。
> 原则：先读 HDRP 源码再实现；本项目的 temporal v1 是简化路径，不冒充 HDRP 的完整 PBR/RT 实现。

## 1. HDRP 源码依据

### 1.1 SSAO

- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.AmbientOcclusion.cs:130-188`
  - `RenderAmbientOcclusion()` 顺序：`RenderAO -> SpatialDenoiseAO -> TemporalDenoiseAO -> UpsampleAO`。
  - `temporalAccumulation = settings.temporalAccumulation.value && MotionVectors enabled`。
  - 首帧/分辨率变化通过 `m_AOHistoryReady = !AllocateAmbientOcclusionHistoryBuffer(scale)`；不可用时用 `GTAOCopyHistory` 把当前 blurred AO 写入 current history。
- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.AmbientOcclusion.cs:330-396`
  - temporal pass 读取 `_AOPackedBlurred`、`_AOPackedHistory`、`_CameraMotionVectorsTexture`，写 `_AOOutputHistory` 和 `_OcclusionTexture`。
- `Runtime/Lighting/ScreenSpaceLighting/GTAOTemporalDenoise.compute:10-109`
  - history 打包：`PackFloatToR8G8(depth)`、AO、motion length。
  - 3x3 当前帧 AO min/max/avg；motion 重投影 `prevFrameNDC = uv - motionVector`。
  - `motionVecWeighting = saturate(motionVecLength * 100.0)`；`feedback = lerp(0.85, 0.95, weight^2)`。
  - depth similarity `saturate(pow(prevDepth / currDepth, 1) + 0.01)`；history clamp + nudge。
- `Runtime/Lighting/ScreenSpaceLighting/GTAOCopyHistory.compute:10-15`
  - 首帧直接把当前 packed AO 复制到 history。
- `Runtime/Lighting/ScreenSpaceLighting/GTAOCommon.hlsl:130-168`
  - HDRP 打包 AO 和 depth；项目输出 visibility，不采用 HDRP `OutputFinalAO` 语义。
- `Runtime/RenderPipeline/Camera/HDCamera.cs:1758-1772`
  - AO history 为 `R8G8B8A8_UNorm`，双缓冲，scale 0.5/1.0，分辨率变化重建。
- `Runtime/Lighting/ScreenSpaceLighting/ScreenSpaceAmbientOcclusion.cs:43/49`
  - `temporalAccumulation` 默认 true；`ghostingReduction` 默认 0.5。

### 1.2 SSR

- `Runtime/RenderPipeline/HDRenderPipeline.LightLoop.cs:1079-1116`
  - `_SsrAccumulationAmount = pow(2, lerp(0, -7, accumulationFactor))`；默认 `accumulationFactor=0.75`，即新样本约 2.6%，历史约 97.4%。
  - 首帧/`cameraFrameCount <= 3` 强制 `_SsrAccumulationAmount=1`，不读历史。
  - `_SsrPBRSpeedRejection`、`_SsrPBRBias`、`_SsrPRBSpeedRejectionScalerFactor` 控制速度拒绝。
- `Runtime/RenderPipeline/HDRenderPipeline.LightLoop.cs:1258-1261`
  - `ScreenSpaceReflectionAccumulation` 当前帧与上一帧 history 通过 `GetCurrentFrameRT/GetPreviousFrameRT` 导入。
- `Runtime/RenderPipeline/HDRenderPipeline.LightLoop.cs:1322-1422`
  - trace 后先 reprojection，再 accumulate；accumulate 有 surface/hit motion vector 组合与 debug kernel。
  - `previousAccumNeedClear` 在首帧/`resetPostProcessingHistory` 时清历史。
- `Runtime/Lighting/ScreenSpaceLighting/ScreenSpaceReflections.compute:574-706`
  - reprojection：trace 输出 hit NDC；用 hit 位置 motion 重投影到上一帧 color pyramid，输出 `RGB=color, A=1`。
- `Runtime/Lighting/ScreenSpaceLighting/ScreenSpaceReflections.compute:708-814`
  - accumulate：`result = lerp(previous, original, coefExpAvg)`；`coefExpAvg` 由 motion speed 和 accumulation amount 决定；非有限值清零。
  - 项目 v1 不做 GGX VNDF stochastic trace、hit-point reprojection、surface/hit 双 motion、color pyramid；只做当前帧 SSR 结果的双缓冲 history + surface motion 重投影 + depth 拒绝。
- `Runtime/Lighting/ScreenSpaceLighting/ScreenSpaceReflection.cs:120-185`
  - `usedAlgorithm` 默认 `Approximation`；`accumulationFactor` 默认 0.75；`screenFadeDistance` 默认 0.1；`speedSurfaceOnly/speedTargetOnly` 默认 true。
  - 项目默认 temporal off，避免改变 M11.5 路径；开启后使用 **current-dominant** history 权重 0.1（HDRP PBRAccumulation 是 history-dominant），因为项目 trace 是确定性 march，不是 HDRP 的随机 GGX 采样。

### 1.3 SSGI

- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.ScreenSpaceGlobalIllumination.cs:80-110`
  - `EvaluateIndirectDiffuseHistoryValidity0()` 合并 full-res / ray-traced history mask 与相机级 history validity。
  - 首帧、相机 reset、效果模式变化时 history validity 置 0。
- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.ScreenSpaceGlobalIllumination.cs:155-221`
  - `TraceSSGI()` 选择 full/half trace + reproject kernel；SSGI 依赖 depth pyramid、normal、stencil、motion vectors 和 light list。
  - `allowSsgi = colorPyramidHistoryIsValid && !isFirstFrame`，首帧不启用 SSGI。
- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.ScreenSpaceGlobalIllumination.cs:400-468`
  - `DenoiseSSGI()` 顺序：`HDTemporalFilter.Denoise -> HDDiffuseDenoiser.Denoise`。
  - temporal 参数：`historyValidity`、`exposureControl=true`、`occluder/receiverMotionRejection=false`、low-res multiplier。
  - SSGI history buffer 为 `RaytracedIndirectDiffuseHF`，单通道/颜色两套 kernel；随后做 diffuse spatial denoiser。
- `Runtime/Lighting/ScreenSpaceLighting/HDRenderPipeline.ScreenSpaceGlobalIllumination.cs:470-517`
  - `RenderSSGI()` 顺序：`Trace -> Denoise(Temporal + Diffuse) -> Upscale`；项目 v1 保持 `Trace -> Temporal -> Spatial Denoise -> Composite`。
- `Runtime/RenderPipeline/Raytracing/Shaders/Denoising/TemporalFilter.compute:90-260`
  - `ValidateHistory`：背景、history validity、reprojection 越界、history depth 背景、position radius、normal dot、object motion。
  - `TEMPORAL_ACCUMULATION`：history alpha 存 sample count；`sampleCount >= 8 -> 0.93`，否则 `sampleCount/(sampleCount+1)`。
  - `history = color*(1-accumulationFactor) + history*accumulationFactor`；首帧/无效 history 只取当前帧。
- `Runtime/RenderPipeline/Raytracing/HDTemporalFilter.cs:223-315`
  - temporal pass 读 noisy buffer、history、depth、normal、motion、validation；输出独立 RGBA16F，再 `CopyHistory` 写回 history。
- `Runtime/RenderPipeline/Raytracing/HDDiffuseDenoiser.cs:86-...`
  - temporal 后接 spatial bilateral/gather；项目已有 9x9 depth-aware denoise，保留作为 SSGI 后处理。
- `Runtime/Lighting/ScreenSpaceLighting/ScreenSpaceGlobalIllumination.compute:200-330`
  - HDRP 的 hit-point reprojection 会重投影到上一帧 color pyramid；本项目 v1 不做 hit-point reprojection，只重投影接收面。
  - 项目 temporal v1 用 surface motion + depth/normal 拒绝 + sample-count 累积；无 exposure re-expose、无 color pyramid。

## 2. 本项目实现

### 2.1 SSAO

- 设置：`src/render/postprocess/ssao_settings.h:8-17`，新增 `temporalAccumulation`，默认 false。
- history：`src/render/passes/forward_renderer.cpp:1328-1378`。
  - 分辨率 = `ssaoResolution(renderWidth, renderHeight, halfResolution)`。
  - 格式 `RGBA8`：`r=visibility`、`g/b=rawDepth` 16-bit、`a=1`。
  - `ensureSsaoHistory()` / `releaseSsaoHistory()`；resize/render-scale/half-res/temporal 开关变化 reset。
- pass：`src/render/passes/forward_renderer.cpp:3573-3664`。
  - `SSAO -> SSAO Blur -> SSAO Temporal -> SSAO Upsample`。
  - 读 `ssaoBlur`、`motionVector`、`depthPyramid`、上一帧 history；写下一帧 history。
  - 首帧/`historyValid=false` 直接写当前 AO + depth，不读 history。
- 重投影沿用 TAA 语义：`prevUv = uv - vec2(motion.x, -motion.y)`；越界/深度不匹配时 history 权重置 0。
- `u_ssao_params3.x=historyValid`、`.y=feedback`（固定 0.90）、`.z=maxMotionPixels`（32 px）、`.w` 保留。
- temporal off 不创建 temporal pass，upsample 仍读 `ssaoBlur`，保证旧路径。
- debug：`ssao-raw` 显示 half-res trace；`ssao-history` 显示上一帧 temporal history 的 `.r`；`ssao` / `ssao-denoised` 显示 blur+temporal+upsample 后的 final AO。

### 2.2 SSR

- 设置：`src/render/postprocess/ssr_settings.h:5-16`。
  - 新增 `temporalAccumulation`（默认 false）和 `temporalWeight`（默认 0.1；仅对当前帧命中的像素作为 history 权重）。
  - `sanitizeSsrSettings()` 把 `temporalWeight` 夹到 0..1。
- uniform：`config/uniforms/ssr.idl` 新增 `params3=(historyValid, historyWeight, maxMotionPixels, unused)`；`SsrUniforms` 32 B -> 48 B。
- history：`src/render/passes/forward_renderer.cpp:1388-1440`。
  - 双缓冲 `RGBA16F`，全分辨率；`RGB=SSR reflection`，`A=current raw depth`（用于 depth 拒绝）。
  - `ensureSsrHistory()` / `releaseSsrHistory()`；resize/render-scale/temporal 开关变化 reset。
- pass：`src/render/passes/forward_renderer.cpp:3832-3867`。
  - 顺序 `SSR -> SSR Temporal -> SSR Composite`，temporal 在 Deferred Lighting 后、Forward Only Opaque 前。
  - temporal 读 `ssr`、`depthPyramid`、`motionVector`、上一帧 history，写下一帧 history；`resources.ssr` 改为 history 供 composite/debug 使用。
  - 首帧/`historyValid=false` 不读 history。
- 渲染：`src/render/passes/forward_renderer.cpp:4768-4795`。
  - 绑定 `s_ssrInput`(0)、`s_motionVectors`(1)、`s_ssrHistory`(2)、`s_depthPyramid`(4)。
  - `u_ssr_params3.x=historyValid`、`.y=temporalWeight`、`.z=32 px`。
- shader：`shaders/passes/ssr_temporal.fs.sc:1-45`。
  - `currentFound = currentSample.a > 0.5`；仅在当前帧命中时混入 history。
  - 重投影 `prevUv = uv - vec2(motion.x, -motion.y)`；越界、depth 差超过 2%、motion 超过 32 px 时权重置 0。
  - 当前帧 miss 时不使用 history，避免把已经消失的反射拖成 ghost；这是与 HDRP PBRAccumulation 的有意差异。
  - 输出 alpha = 当前 raw depth，供下一帧比较。
- temporal on 时 SSR trace 用 `RGBA16F` 保留 alpha（`currentFound` / depth）；temporal off 保持旧 `selectHdrFormat()`，确保旧路径 0 diff。
- CLI：`--ssr-temporal` / `--no-ssr-temporal`；`Application` 和 `runRenderTest()` 都把 `SsrSettings` 传给 renderer。
- 首帧日志：`ssr: history created ...`、`ssr: temporal enabled, weight=...`。
- 诊断：`ssr_temporal`、`ssr_history`、`ssr_frames`；`--debug-view=ssr` 显示 temporal 输出（temporal on 时即 history）。
- debug：`ssr-raw` 显示当前帧 trace；`ssr-history` 显示上一帧 temporal history；`ssr` / `ssr-denoised` 显示 temporal/final reflection。SSR 没有独立 spatial denoise，因此 denoised 与 current temporal output 相同。

### 2.3 SSGI

- 设置：`src/render/postprocess/ssgi_settings.h:8-19`，新增 `temporalAccumulation`，默认 false；保持 SSGI 现有 intensity/rays/steps 语义不变。
- uniform：`config/uniforms/ssgi.idl` 新增 `params4=(historyValid, depthThreshold, maxHistoryFrames, unused)`；`SsgiUniforms` 48 B -> 64 B。
- history：`src/render/passes/forward_renderer.cpp:1454-1530` 的 `ensureSsgiHistory()` / `releaseSsgiHistory()`。
  - 双缓冲 `RGBA16F`：`RGB=temporal SSGI`、`A=sample count`。
  - 双缓冲 `R32F`：上一帧 low-res raw depth，用于 depth rejection。
  - 双缓冲 `RGBA8`：上一帧 encoded normal，用于 normal rejection（HDRP `MAX_NORMAL_DIFFERENCE=0.65`）。
  - 分辨率 = `ssgiResolution(renderWidth, renderHeight, halfResolution)`；resize/render-scale/half-res/temporal 开关变化 reset。
- pass：`addSSGIPasses()` 顺序 `SSGI Trace -> SSGI Temporal -> SSGI Denoise -> SSGI Composite`。
  - temporal 读 `ssgiRaw`、`motionVector`、`depthPyramid`、`gbuffer2`、上一帧 history + history depth + history normal。
  - temporal 写下一帧 history（MRT：attachment 0 = RGBA16F，attachment 1 = R32F depth，attachment 2 = RGBA8 normal）。
  - `SSGI Denoise` 的输入在 temporal on 时为 history，off 时仍为 `ssgiRaw`，因此 temporal off 路径不变。
  - `u_ssgi_params4.x=historyValid`；`y=0.02` raw-depth 相对阈值；`z=8` max history frames。
- shader：`shaders/passes/ssgi_temporal.fs.sc:1-76`。
  - `prevUv = uv - vec2(motion.x, -motion.y)`。
  - history depth 与当前 depth 差超过 `max(rawDepth*0.02, 0.0001)`、history/current normal 的 dot 小于 0.65、越界、背景、首帧时拒绝 history。
  - 有效 history：`accumulation = sampleCount >= 8 ? 0.93 : sampleCount/(sampleCount+1)`；输出 alpha = `min(sampleCount+1, 8)`。
  - 无效 history：输出当前 SSGI + sampleCount=1；首帧不读未初始化 history。
  - background 写 0 + sampleCount=0；下一帧继续跳过。
- 已知 v1 差异：
  - 不做 HDRP `HDTemporalFilter.ValidateHistory` 的 position radius / stencil/object-motion 细分；当前用 depth + normal + motion + 越界。
  - 不做 HDRP `exposureControl` re-expose；SSGI 在 exposure 前，项目保持线性场景颜色。
  - 不做 hit-point reprojection、color pyramid、receiver/occluder motion rejection。
  - temporal 后仍走项目现有 9x9 depth-aware spatial denoise，不是 HDRP `HDDiffuseDenoiser` 的点分布/半球核。
- CLI：`--ssgi-temporal` / `--no-ssgi-temporal`；`Application` 和 `runRenderTest()` 把 `SsgiSettings` 传给 renderer。
- 诊断：`ssgi_temporal`、`ssgi_history`、`ssgi_frames`；`--debug-view=ssgi` 仍显示 spatial denoise 后的结果。
- debug：`ssgi-raw` 显示当前帧 trace（不采样 depth、不做 9x9 filter）；`ssgi-history` 显示上一帧 RGBA16F RGB history；`ssgi` / `ssgi-denoised` 显示 9x9 depth-aware denoise 后的结果。

### 2.4 Raw/history debug views

- 对齐 HDRP `FullScreenDebugMode.ScreenSpaceReflectionsPrev/Accum`（`HDRenderPipeline.LightLoop.cs:1437-1438`）和 `ScreenSpaceAmbientOcclusion` / `ScreenSpaceGlobalIllumination`（各 pass 末尾 `PushFullScreenDebugTexture`）。
- 本项目 v1 的 `-history` 统一显示**上一帧 temporal history**，用于检查 reprojection/depth/normal rejection；不是当前帧刚写入的新 history。首帧 history 未完成时视图不可用，自动回退普通画面。
- `-raw` 显示 current trace；`-denoised` 是现有 `ssao`/`ssr`/`ssgi` 的别名：
  - SSAO：`ssao-raw`、`ssao-history`、`ssao-denoised`。
  - SSR：`ssr-raw`、`ssr-history`、`ssr-denoised`。
  - SSGI：`ssgi-raw`、`ssgi-history`、`ssgi-denoised`。
- `-history` CLI 自动打开对应 temporal 开关；显式 `--no-*-temporal` 仍可覆盖并回退普通画面。
- debug shader：SSAO/SSR 复用现有 `debug_ssao.fs.sc` / `debug_ssr.fs.sc`；SSGI raw/history 新增 `debug_ssgi_raw.fs.sc`，只复制 RGB 并 clamp 8，不采样 depth pyramid。

## 4. 暂不做

- 不做 HDRP PBRAccumulation 的 GGX VNDF stochastic trace、hit-point reprojection、surface/hit 双 motion、color pyramid。
- 不做 SSR/SSGI 的 Hi-Z / color pyramid mip 采样；Hi-Z 归 A09/M12.5。
- 不做 SSGI exposure re-expose、receiver/occluder motion rejection；v1 用 depth + normal + motion + 越界。
- 不做透明 SSR、透明 SSAO、透明 SSGI；透明路径保持 M2 边界。
- 不修改 SSAO radius/intensity/step/upsample 语义；不修改 SSR/SSGI 单帧 trace/composite 语义（temporal off 0 diff）。
- debug 只读取已有 trace/history，不改变正常渲染路径；`-history` 不实现 HDRP 的 current accum/prev 双视图，只显示上一帧 history。
