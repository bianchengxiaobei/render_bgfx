# M12.2 Shadow Quality v2 (B01)

> 状态：**进行中**。P0 shadow banding 已修复；area + point PCSS 共存已完成；cached directional static 已完成。EVSM/VSM/IMS、cached directional mixed、transparent/SSS/cloud shadow 仍未实现。
> 参考源码：`E:\Learn\Graphics\Packages\com.unity.render-pipelines.high-definition\Runtime`。

## 1. P0 Shadow Banding（已完成）

- D3D11 `shadow.context` 原为 `Storage` index buffer（`R32_UINT` SRV），shader 用 typed `Buffer<float4>` 读取，D3D 读到全 0；Vulkan 因 raw/structured 路径不同仍能读到数据，造成“Vulkan banding”。
- 改为 `StorageVertex` + `RGBA32F` typed context；`shadow.contextArea` 复用同一 layout：`src/render/shadows/shadow_manager.cpp:381`。
- PCF texel 从 `1/viewport` 改为 `atlasRect.xy * requestParams.zw = 1/atlasSize`：`shaders/lighting/shadows.sc:440/513/586`。point 256/2048 的 8× tap 间距和 directional 1024/2048 的 2× 间距被消除。
- Point face 加 6° guard angle，参考 HDRP `HDShadowUtils.cs:374-410`：`shadow_manager.cpp:23/728`。
- 首帧对 directional/punctual/area atlas 做完整 depth clear：`src/render/passes/forward_renderer.cpp:6649`，消除未初始化 tile 采样和 D3D run-to-run 差异。\n- 验证：修复首帧 shadow atlas 未初始化区域后，`m26_ssgi_corner` / `m122_area_point_dir` 带 shadows D3D/VK 均 **0 diff**；M12.2 可做带 shadows 跨后端对比。首帧完整 clear 也消除了此前 169 px 的 D3D run-to-run 非确定性。

## 2. Area + Point PCSS 共存（已完成）

- 原实现中 area depth 占用 stage 13，point PCSS 与 area PCSS 不能同时开启，point 会回退 5×5 tent。
- 现在 stage 9 绑定 **point depth**（手动比较），point PCF/PCSS 均从 stage 9 读取；stage 13 保留 area depth；stage 12 保留 directional depth/PCSS。这样 point PCSS 不再依赖 stage 13。
- `hbgPcssRawDepth(punctual)` 从 `s_shadowMapPunctual`（stage 9）取 raw depth；去掉 area-active 时回退 tent 的旧分支。
- 默认 PCF 路径由硬件 compare sampler 改为 stage 9 point fetch + 手动 `>=` 比较；配合首帧完整 atlas clear，D3D/VK 带 shadows 达到 **0 diff**。
- 验证场景 `m122_area_point`（4 area + 1 point，all PCSS），1280×720：
  - forward D3D/VK **0 diff**
  - deferred D3D/VK **0 diff**
  - point PCSS -> PCF5x5 变化 **59.35 dB**（5,552 px）；area PCSS -> PCF5x5 变化 **75.65 dB**（3,292 px），证明两者同时生效。
- Stage 分配：stage 9 = point depth，stage 12 = directional depth，stage 13 = area depth；directional/point/area 三种 PCSS 可同时开启，互不覆盖。`m122_area_point_dir`（4 directional + 6 point + 4 area，全 PCSS）D3D/VK **0 diff**。

## 3. Cached Directional Static（已完成，mixed 未实现）

- `ShadowSettings::cachedDirectionalShadows`、`config/shadows.json`、`--directional-shadow-cache` / `--no-directional-shadow-cache`。
- 新增 `shadow.cachedDirectionalAtlas`；`activeDirectionalTexture()` 在 cache eligible 时返回 cached atlas。
- 缓存 hash 包含 scene objects/materials、light 参数、shadow settings、cascade 配置、request viewProj/viewport；因此 light/scene/camera 变化自动失效。
- 命中时 directional requests 标记 `isCached`，shadow pass 只 `beginCachedPass`（不 clear、不 draw），保留 atlas 内容。
- 静态 1280×720、8 帧：draw **75 -> 63**，`shadow_drawn` **31 -> 15**，`shadow_dir_cache=true`、`shadow_cached_dir=4`；640×360 下 139 -> 262 fps（调试构建，仅路径证据）。静态 cache on/off **0 diff**、D3D/VK **0 diff**；`--camera-orbit` 8 帧 cache on/off **0 diff**，`shadow_cached_dir=0`，证明 camera/scene 变化会失效。
- 仍缺 HDRP 的 mixed cached directional（静态 cached + 动态 partial update）；当前有运动 caster/camera 时整体失效并回退 every-frame。诊断字段：`shadow_dir_cache` / `shadow_cached_dir`。
- HDRP 对照：`HDCachedShadowAtlas.cs`、`HDShadowManager.cs` cached request flags、`HDShadowContext.hlsl:13`。

## 4. EVSM / VSM / IMS（未实现）

- 当前 `ShadowFilter` 仍为 `off/pcf3x3/pcf5x5/pcf7x7/pcss`；没有 moment atlas、moment blur、SAT 或 4-moment 重建。
- HDRP 参考：
  - EVSM：`HDShadowAtlas.cs:143-165`（half-res R32G32 moment atlas + blur）、`HDShadowSampling.hlsl:220-254`、`HDShadowAlgorithms.hlsl:57-61`。
  - IMS：`HDShadowAtlas.cs:647-723`（RGBA32F + SAT）、`HDIMS.hlsl:269-323`、`HDShadowManager.cs:334`。
  - VSM 采样：`HDShadowSampling.hlsl:206-216`。
- 下一实现步骤：新增 moment atlas 资源与 fullscreen moment 生成 pass；directional/point/area 分别绑定 stage 12/9/13；filter mode 5/6/7；先用 5×5 moment gather 近似，再按 HDRP 增加 blur/SAT。每项独立开关并保持旧 filter off 路径。

## 5. Transparent / SSS / Cloud Shadow（阻塞）

- 当前没有 SSS/transmission 材质、没有云/volume cloud 系统；transparent 物体也不在 shadow draw list（`kRenderQueueRangeAllOpaque`）。不能伪造 HDRP semi-transparent color shadow / SSS shadow / cloud shadow。
- 这些项依赖 M12.3 材质（SSS/transmission）与后续 cloud system；M12.2 先记录为阻塞，不作为已完成。
