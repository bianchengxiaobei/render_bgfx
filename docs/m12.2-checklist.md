## 1. P0 Shadow Banding（已完成）

- D3D11 `shadow.context` 原为 `Storage` index buffer（`R32_UINT` SRV），shader 用 typed `Buffer<float4>` 读取，D3D 读到全 0；Vulkan 因 raw/structured 路径不同仍能读到数据，造成“Vulkan banding”。
- 改为 `StorageVertex` + `RGBA32F` typed context；`shadow.contextArea` 复用同一 layout：`src/render/shadows/shadow_manager.cpp:381`。
- PCF texel 从 `1/viewport` 改为 `atlasRect.xy * requestParams.zw = 1/atlasSize`：`shaders/lighting/shadows.sc:440/513/586`。point 256/2048 的 8× tap 间距和 directional 1024/2048 的 2× 间距被消除。
- Point face 加 6° guard angle，参考 HDRP `HDShadowUtils.cs:374-410`：`shadow_manager.cpp:23/728`。
- 首帧对 directional/punctual/area atlas 做完整 depth clear：`src/render/passes/forward_renderer.cpp:6649`，消除未初始化 tile 采样和 D3D run-to-run 差异。\n- 验证：修复首帧 shadow atlas 未初始化区域后，`m26_ssgi_corner` / `m122_area_point_dir` 带 shadows D3D/VK 均 **0 diff**；M12.2 可做带 shadows 跨后端对比。首帧完整 clear 也消除了此前 169 px 的 D3D run-to-run 非确定性。

## 2. Area + Point PCSS 共存（已完成）

- 原实现中 area depth 占用 stage 13，point PCSS 与 area PCSS 不能同时开启，point 会回退 5×5 tent。
- 现在 stage 9 绑定 **point depth**（手动比较），point PCF/PCSS 均从 stage 9 读取；stage 13 保留 area depth；stage 12 保留 directional depth/PCSS。这样 point PCSS 不再依赖 stage 13。
- `hbgPcssRawDepth(punctual)` 从 `s_shadowMapPunctual`（stage 9）取 raw depth；去掉 area-active 时回退 tent 的旧分支。
- 默认 PCF 路径由硬件 compare sampler 改为 stage 9 point fetch + 手动 `>=` 比较；配合首帧完整 atlas clear，D3D/VK 带 shadows 达到 **0 diff**。
- 验证场景 `m122_area_point`（4 area + 1 point，all PCSS），1280×720：
  - forward D3D/VK **0 diff**
  - deferred D3D/VK **0 diff**
  - point PCSS -> PCF5x5 变化 **59.35 dB**（5,552 px）；area PCSS -> PCF5x5 变化 **75.65 dB**（3,292 px），证明两者同时生效。
- Stage 分配：stage 9 = point depth，stage 12 = directional depth（directional IMS 时改为 SAT），stage 13 = area depth；directional/point/area 三种 PCSS 可同时开启，互不覆盖。`m122_area_point_dir`（4 directional + 6 point + 4 area，全 PCSS）D3D/VK **0 diff**。

## 3. Cached Directional Per-Cascade（v1；HDRP mixed 未完成）

- `ShadowSettings::cachedDirectionalShadows`、`config/shadows.json`、`--directional-shadow-cache` / `--no-directional-shadow-cache`。
- 新增 `shadow.cachedDirectionalAtlas`；`activeDirectionalTexture()` 在 cache eligible 时返回 cached atlas。
- 缓存 hash 包含 scene objects/materials、light 参数、shadow settings、cascade 配置、request viewProj/viewport；因此 light/scene/camera 变化自动失效。
- 命中时 directional requests 标记 `isCached`，shadow pass 只 `beginCachedPass`（不 clear、不 draw），保留 atlas 内容。
- 静态 1280×720、8 帧：draw **75 -> 63**，`shadow_drawn` **31 -> 15**，`shadow_dir_cache=true`、`shadow_cached_dir=4`；640×360 下 139 -> 262 fps（调试构建，仅路径证据）。静态 cache on/off **0 diff**、D3D/VK **0 diff**；`--camera-orbit` 8 帧 cache on/off **0 diff**，`shadow_cached_dir=0`，证明 camera/scene 变化会失效。
- v1 已从全 atlas 单一 hash 改为 **per-request hash**：每个 directional request 对 viewProj、atlas slot、filter/soft-shadow 参数和其 shadow frustum 内 caster 的 world/mesh 做 hash；未变化 cascade 标记 `isCached`，变化的 cascade 只重绘自己的 viewport，cached atlas 的其他 cascade 保留。
- 仍缺 HDRP 的完整 mixed cached directional：HDRP 在单个 cascade 内把 static caster 缓存在 cached atlas、dynamic caster 每帧叠加；本项目没有 caster static flag，也还没有静态/动态分层，因此一个 cascade 内有 caster 变化时整张 cascade 重绘。camera/light 变化仍会使全部 cascade 失效。
- 640×360、静态 `m10_dir_shadow` 4 帧 cache on/off **0 diff**，warm 帧 `shadow_dir_cache=true`、`shadow_cached_dir=4`；`hbg_tests` 248/32,525。诊断字段：`shadow_dir_cache` / `shadow_cached_dir` / `directionalCacheMixed()`。
- 新增 directional cache keeps unaffected cascades：cache-off probe 找只与部分 cascade 相交的 caster，移动 0.1 后断言未受影响 cascade 仍 cached、directionalCacheMixed() 为 true。
- HDRP 对照：`HDCachedShadowAtlas.cs`、`HDShadowManager.cs` cached request flags、`HDShadowContext.hlsl:13`。

## 4. EVSM/VSM/MSM/IMS v1

- 当前 `ShadowFilter` 新增 `Evsm`（`evsm`，shader mode 5）、`Vsm`（`vsm`，shader mode 6）、`Msm`（`msm`，shader mode 7）与 directional-only `Ims`（`ims`，shader mode 8）；
  `config/shadows.json` 的 `directionalFilter` / `punctualFilter` / `areaFilter` 以及
  `--shadow-filter` / `--shadow-directional-filter` / `--shadow-punctual-filter` 均接受；`ims` 仅 directional，punctual/area 会被 sanitize 回 PCF5x5。
- HDRP 参考：
  - `HDShadowSampling.hlsl:206-254`：VSM/EVSM 1-tap Chebyshev 采样。
  - `ShadowMoments.hlsl:5-40`：`ShadowMoments_ChebyshevsInequality`、
    `ShadowMoments_WarpDepth_PosOnlyBaseTwo`；指数以 log2(e) 预乘。
  - `HDShadowManager.cs:890-899`：area quality 非 High 时选择 EVSM；
    `HDGpuLightsBuilder.LightLoop.cs:1030-1038`：`evsmParams = (exponent*log2e, leak, variance, blurPasses)`。
  - `HDShadowAtlas.cs:143-165/531-643`：HDRP 的 half-res `R32G32_SFloat` moment atlas + blur。
- 本项目 v1 没有新增 moment atlas / compute blur / SAT。`shadows.sc` 用现有 raw depth
  在 atlas 内做 **3x3 EVSM moment gather**，再按 HDRP 公式做 Chebyshev：
  - exponent = `15 * log2(e) = 21.640392`，lightLeakBias = `0`，varianceBias = `1e-5`（HDRP 默认）。
  - directional 使用 stage 12 raw depth（仅 `HBG_SHADOW_POINT_SAMPLER` 路径；advanced deferred /
    advanced variant 的 stage 12 被 GBuffer4 占用时回退 PCF7x7；volumetric fog 保持 compare 路径）。
  - point/spot 使用 stage 9 raw depth；area 使用 stage 13 raw depth。
  - 与 `HDShadowSampling.hlsl:222-254` 的 difference：HDRP 采样的是已 blur 的 moment atlas，
    本项目是屏幕空间 3x3 local gather；不声称等价于 HDRP EVSM 质量路径。
- VSM v1 复用同一 local 3x3 moment gather，不做 EVSM 的 exponential warp：
  - 参考 `HDShadowSampling.hlsl:206-218` 的 `SampleShadow_VSM_1tap` 与
    `ShadowMoments.hlsl:11-22` 的 `ShadowMoments_ChebyshevsInequality`。
  - moments = `(depth, depth²)`，`minVariance = varianceBias = 1e-5`，`lightLeakBias = 0`；
    directional/point/spot/area 的 stage 选择与 EVSM 相同。
  - HDRP 该路径读取已 blur 的 VSM moment atlas；本项目仍是 local 3x3 gather，不声称等价。
- MSM v1 使用 4 个 raw-depth moments 做 local gather，参考 HDRP：
  - `HDShadowSampling.hlsl:260-282` 的 `SampleShadow_MSM_1tap`。
  - `ShadowMoments.hlsl:55-135` 的 `ShadowMoments_SolveMSM`、`SolveDelta3MSM`、`SolveDelta4MSM`。
  - moments = `(depth, depth², depth³, depth⁴)`；`momentBias = 6e-7`、`lightLeakBias = 0`；
    roots 在 `[0,1]` 外时使用 Delta4，否则 Delta3；退化窗口回退到 local VSM/Chebyshev。
  - stage 选择与 VSM/EVSM 相同；advanced deferred/variant advanced 的 directional 回退 PCF7x7，volumetric fog 保持 compare。
  - 仍未实现 HDRP IMS 的 4-moment moment atlas + SAT；当前是 local 3x3 gather，不声称等价。
- IMS v1（directional-only）已实现：
  - 参考 `HDShadowSampling.hlsl:384-412` 的 `SampleShadow_IMS`、`HDIMS.hlsl:269-334` 的
    `SampleShadow_IMS`、`Compute4MomentAverageBlockerDepth`、`Compute4MomentUnboundedShadowIntensity`，
    以及 `MomentShadows.compute` 的 `ComputeMomentShadows` / `MomentSummedAreaTableHorizontal` /
    `MomentSummedAreaTableVertical`。
  - `ShadowManager` 新增 `shadow.directionalMoments`（RGBA32F）与
    `shadow.directionalMomentSat`（RGBA32U）两张 directional atlas 纹理；方向光片元着色器在
    `ims` 模式下把 stage 12 从 raw depth 切换为 SAT sampler，point/area 仍分别用 stage 9/13。
  - 3 个 compute pass：`ShadowMoments`、`ShadowSatHorizontal`、`ShadowSatVertical`；moment 使用
    HDRP 的 optimized 4-moment basis，SAT 按 shadow request slot 做 per-row/per-column 前缀和。
    `Shaderc` 输出：`shadow_moments.cs.bin`、`shadow_sat_horizontal.cs.bin`、`shadow_sat_vertical.cs.bin`。
  - 采样端实现 HDRP 的 optimized-to-canonical、blocker 搜索、unbounded 4-moment 解算；blocker
    search/filter 均使用 RGBA32U integer SAT（HDRP `ComputeIntegerRectangleAverage_uint4` / `ComputeRectangleAverage_uint4`），
    并加入 HDRP `EstimatePenumbraSize` / `ComputeDirectionalLightSoftShadowParameters` 对应的
    light-angle penumbra 与 `maxDepthBias`。`directionalLightAngle`、`directionalMaxDepthBias`、
    `imsKernelSize` 已进入 `ShadowSettings` 与 CLI（`--shadow-light-angle` /
    `--shadow-max-depth-bias` / `--shadow-ims-kernel-size`）。
  - IMS 参数按 request 写入 shadow context 的 texel9（与 PCSS 参数复用；IMS 路径不读
    blocker/filter 字段），包含 `(kernelSize, lightX, lightY, maxDepthBias)`。这与 HDRP 把
    projection/soft-shadow 参数放在每个 `HDShadowData` 的做法一致，cascade 不再共享首个
    request 的参数；blocker 搜索的退化方差 guard 已降到 HDRP 等价量级，修复了 IMS 在实际
    深度分布上退化为“无 blocker”的问题。
  - advanced deferred / advanced variant 的 stage 12 被 GBuffer4 占用，IMS 在这些路径回退
    PCF7x7；volumetric fog 保持 compare；point/area 的 `ims` 配置被 sanitize 为 PCF5x5。
  - 2048² 时 moment+SAT 约占 128 MiB；仅对 directional atlas 分配，cached directional 复用同一对
    moment/SAT，每帧从 active directional atlas 重建。
- 整数 fixed-precision SAT 已实现（参考 HDRP `MomentShadows.compute` / `HDIMS.hlsl`）：
  - moment atlas 保持 `RGBA32F`；SAT 改为 **`RGBA32U`**。horizontal/vertical compute 用 `uvec4`前缀和，
    `fixedPrecision = 4294967295 / ceil(1 + kernelSize)^2`，最终 rectangle integral 乘 `1/fixedPrecision`。
  - directional raw depth 移到 **stage6 normal sampler**，PCF/PCSS 改为显式 raw-depth compare；
    stage12 固定为 **`USAMPLER2D` integer SAT**，避免与 punctual/stage 冲突，也不再需要 `Buffer<uint4>`/`COMPUTE_WRITE` CPU update。
  - 640×360 D3D11：PCF 与旧 float SAT 版本 **0 diff**；integer IMS vs 旧 float IMS **30.40 dB / max139 / 3,018 px**
    （差异集中在 shadow 边缘，来自 fixed precision 替代 float 前缀和）；integer IMS vs PCF **26.28 dB / 4,810 px**。
  - D3D11/Vulkan integer IMS **61.45 dB / max114 / 21 px**；forward vs deferred **58.66 dB / max89**；
    PCF D3D/VK **0 diff**。
  - 2048² moment+SAT 仍约 128 MiB；advanced deferred/variant 的 stage12 GBuffer4 路径仍回退 PCF7x7。
- 仍开放：moment/separable blur、advanced stage、cached directional 单 cascade 内 static/dynamic mixed、
  transparent/SSS/cloud shadow、EVSM per-light exponent/leak 参数。
- HDRP 的 area 默认 EVSM（Medium），本项目默认仍为 `Pcss`，由 profile opt-in；旧 PCF/PCSS 路径不变。

## 5. Transparent / SSS / Cloud Shadow（阻塞）

- 当前没有 SSS/transmission 材质、没有云/volume cloud 系统；transparent 物体也不在 shadow draw list（`kRenderQueueRangeAllOpaque`）。不能伪造 HDRP semi-transparent color shadow / SSS shadow / cloud shadow。
- 这些项依赖 M12.3 材质（SSS/transmission）与后续 cloud system；M12.2 先记录为阻塞，不作为已完成。
