## 1. P0 Shadow Banding（已完成）

- D3D11 `shadow.context` 原为 `Storage` index buffer（`R32_UINT` SRV），shader 用 typed `Buffer<float4>` 读取，D3D 读到全 0；Vulkan 因 raw/structured 路径不同仍能读到数据，造成“Vulkan banding”。
- 改为 `StorageVertex` + `RGBA32F` typed context；`shadow.contextArea` 复用同一 layout：`src/render/shadows/shadow_manager.cpp:381`。
- PCF texel 从 `1/viewport` 改为 `atlasRect.xy * requestParams.zw = 1/atlasSize`：`shaders/lighting/shadows.sc:440/513/586`。point 256/2048 的 8× tap 间距和 directional 1024/2048 的 2× 间距被消除。
- Point face 加 6° guard angle，参考 HDRP `HDShadowUtils.cs:374-410`：`shadow_manager.cpp:23/728`。
- 首帧对 directional/punctual/area atlas 做完整 depth clear：`src/render/passes/forward_renderer.cpp:6649`，消除未初始化 tile 采样和 D3D run-to-run 差异。\n- 验证：修复首帧 shadow atlas 未初始化区域后，旧 area PCSS 时 `m26_ssgi_corner` / `m122_area_point_dir` 带 shadows D3D/VK 均 **0 diff**；HDRP cone 后 `m122_area_point_dir` 为 **83.32 dB / max10 / 219 px**；M12.2 可做带 shadows 跨后端对比。首帧完整 clear 也消除了此前 169 px 的 D3D run-to-run 非确定性。

## 2. Area + Point PCSS 共存（已完成）

- 原实现中 area depth 占用 stage 13，point PCSS 与 area PCSS 不能同时开启，point 会回退 5×5 tent。
- 现在 stage 9 绑定 **point depth**（手动比较），point PCF/PCSS 均从 stage 9 读取；stage 13 保留 area depth；stage 12 保留 directional depth/PCSS。这样 point PCSS 不再依赖 stage 13。
- `hbgPcssRawDepth(punctual)` 从 `s_shadowMapPunctual`（stage 9）取 raw depth；去掉 area-active 时回退 tent 的旧分支。
- 默认 PCF 路径由硬件 compare sampler 改为 stage 9 point fetch + 手动 `>=` 比较；配合首帧完整 atlas clear，D3D/VK 带 shadows 达到 **0 diff**。
- 验证场景 `m122_area_point`（4 area + 1 point，all PCSS），1280×720：
  - 旧 area PCSS：forward D3D/VK **0 diff**；deferred D3D/VK **0 diff**
  - point PCSS -> PCF5x5 变化 **59.35 dB**（5,552 px）；旧 area PCSS -> PCF5x5 变化 **75.65 dB**（3,292 px），证明两者同时生效；area PCSS 现改为 HDRP cone，旧值仅作历史。
- Stage 分配：stage 9 = point depth，stage 12 = directional depth（directional IMS 时改为 SAT），stage 13 = area depth；directional/point/area 三种 PCSS 可同时开启，互不覆盖。`m122_area_point_dir`（4 directional + 6 point + 4 area，全 PCSS）D3D/VK **83.32 dB / max10 / 219 px**（旧 area PCSS 时为 0 diff）。

- 当前 `ShadowFilter` 新增 `Evsm`（`evsm`，shader mode 5）、`Vsm`（`vsm`，shader mode 6）、`Msm`（`msm`，shader mode 7）与 directional-only `Ims`（`ims`，shader mode 8）；
  `config/shadows.json` 的 `directionalFilter` / `punctualFilter` / `areaFilter` 以及
  `--shadow-filter` / `--shadow-directional-filter` / `--shadow-punctual-filter` 均接受；`ims` 仅 directional，punctual/area 会被 sanitize 回 PCF5x5。
- HDRP 参考：
  - `HDShadowSampling.hlsl:206-254`：VSM/EVSM 1-tap Chebyshev 采样。
  - `ShadowMoments.hlsl:5-40`：`ShadowMoments_ChebyshevsInequality`、
    `ShadowMoments_WarpDepth_PosOnlyBaseTwo`；指数以 log2(e) 预乘。
  - `HDShadowManager.cs:890-899`：area quality 非 High 时选择 EVSM；
    `HDGpuLightsBuilder.LightLoop.cs:1030-1038`：`evsmParams = (exponent*log2e, leak, variance, blurPasses)`。
  - `HDShadowAtlas.cs:143-165/531-643`：HDRP 的 half-res `R32G32_SFloat` moment atlas +
    `ConvertAndBlur` / `Blur` / `CopyMoments`；`EVSMBlur.compute:8-9/162-166`：两个 kernel 与 copy；
    `HDShadowAtlas.cs:598-639`：per-request `evsmParams.w` 次 Blur + 奇数次时的 final copy。
- area PCSS 已按 HDRP `PCSS.hlsl:267-360` 的 `FilterScaleOffset` / `BlockerSearch_Area` / `PCSS_Area`
  与 `HDShadowSampling.hlsl:306-357` 的 `SampleShadow_PCSS_Area` 重写：
  - blocker 使用 clumped Fibonacci 采样，filter 使用 uniform Fibonacci 采样；方向由 HDRP LUT 的
    golden-angle 公式生成，sample count 上限 64。
  - softness 先按 `softness * 65 * 4096 / tileResolution` 转为 cone z 距离，并按 near plane 限幅；
    penumbra 使用 HDRP `PenumbraSizePunctual`（`abs((receiver - blocker) / blocker)`），最小半径
    使用 `minFilterSize * 10`。
  - 项目使用标准深度（0=near），HDRP 使用 reversed Z；cone 采样向光源移动，因此使用
    `max(depth - zOffset, 0)`，blocker 判定使用 `rawDepth < coneDepth`；`FilterScaleOffset` 的
    深度分母对应标准深度 `max(depth, 1e-6)`。不使用 HDRP 的 `posSS` 输入，而是由
    `u_global_nonJitteredViewProj` + `u_global_screenSize` 重建屏幕像素，再用 HDRP 同款
    `InterleavedGradientNoise` 帧偏移做 jitter。
  - 仍使用 stage 13 raw area depth + 手动 compare，不新增 sampler/stage；PCSS samples 仍由
    sidecar/CLI 的 blocker/filter count 控制（上限 64）。
- area EVSM 已按 HDRP `EVSMBlur.compute` 的 `ConvertAndBlur` / `Blur` / `CopyMoments` 结构实现；
  directional/punctual EVSM 仍保留 local 3x3 gather。`shadows.sc` 的 EVSM 公式为：
  - exponent = `15 * log2(e) = 21.640426`，lightLeakBias = `0`，varianceBias = `1e-5`，
    blurPasses = `0`（HDRP 默认）。
  - HDRP 9-tap Gaussian 权重（`HDShadowAtlas.cs:311-317`）：
    `0.1531703, 0.1448929, 0.1226492, 0.0929025, 0.06297021`；本项目 compute 在 8x8 group 的 16x16 shared tile 上做 LDS 水平/垂直 9-tap 分离 blur（等价于 HDRP 的 LDS
    可分离核，但布局更简单）。输出 `shadow.areaEvsmMoments` 与 ping-pong copy 均为 half-res
    `RGBA32F`（512² ×2，约 8 MiB）；
    HDRP 原文使用 `R32G32_SFloat`，bgfx shaderc 的 image format 不支持 `rg32f`，因此保留 RGBA32F。
  - area atlas 的 per-request viewport 由 `ShadowEvsmBlur` compute 生成 half-res moments（2x2 point 下采样）；
    area filter 为 `evsm` 时，stage 13 绑定 **blurred moments** 而不是 raw area depth，不再新增 sampler/stage。
  - area EVSM 片元采样按 HDRP `HDShadowAlgorithms.hlsl:198-211` 的 `EvalShadow_AreaDepth`：`blurPassesScale` 为
    `1 + min(4, blurPasses) * 4`，有效坐标按 `EvalShadow_MinMaxCoords`（`HDShadowAlgorithms.hlsl:163-166`）
    `min = atlasOffset + texel * scale`、`max = atlasOffset + (size - 0.5 * scale) * texel` 收缩；EVSM 分支
    `normalBias = 0`。非 EVSM area filter 仍使用原 `normalBias` 与半 texel 边界，避免改变 PCSS/VSM/MSM 行为。
    本项目保留 request 的 depth bias（没有 HDRP 的 slope-scale raster bias 路径），未声称完整 HDRP EVSM 采样等价。
  - 每个光源的 EVSM 参数从 sidecar `lights[].shadow.evsmExponent` / `evsmLightLeakBias` /
    `evsmVarianceBias` / `evsmBlurPasses` 读取，并按 HDRP `HDAdditionalLightData` 的范围
    5..42、0..1、0..0.001、0..8 sanitize。request 存 base-two exponent；context texel9 写入
    `(exponent, leak, variance, blurPasses)`；area compute 的 `u_shadowMomentParams.x` 与片元采样
    使用同一 per-light 值。`evsmBlurPasses` 已按 `HDShadowAtlas.cs:598-639` 接 area：
    `ConvertAndBlur` 写 moment0，随后 ping-pong 执行 N 次 `Blur`（`shadow_evsm_blur_moments`，
    已 EVSM 输入；该 kernel 复用 `u_shadowMomentParams.x`，0=blur、1=copy），N 为奇数时再用
    `CopyMoments` 从 copy 贴回最终 moment0；N=0 与旧版 **0 diff**。该额外 Blur/Copy 目前只用于
    area moment atlas；directional/punctual 的 local 3x3 gather 不消费 `evsmBlurPasses`。
  - directional 使用 stage 12 raw depth（IMS 时为 integer SAT）；point/spot 使用 stage 9 raw depth；
    area 使用 stage 13 blurred moments。
  - advanced material 的 deferred stage 12 仍由 GBuffer4 占用，但其 stage 6/9 raw depth 可用；
    `shadows.sc` 新增 `HBG_SHADOW_ADVANCED_DEPTH_FILTERS`，在 `deferred_lighting_advanced`、
    `forward_advanced`、advanced deferred variant（raster/compute）中启用 directional/point

  - advanced **forward** IMS 已启用：forward advanced 没有 GBuffer4，stage 12 直接绑定 integer SAT；
