## A03：4RT DBuffer、per-channel mask、decal layers、额外 MRT（完成 v1）

- DBuffer 从 3RT 扩为 **4RT RGBA8**：
  - `decal0 = (albedo.rgb, albedoCoverage)`
  - `decal1 = (encodedNormal, normalCoverage)`
  - `decal2 = (metallic, AO, roughness, aoCoverage)`
  - `decal3 = (metallicCoverage, roughnessCoverage, layerMask/255, 0)`
- clear 值为 `(0,0,0,0)`、`(0.5,0.5,0.5,0)`、`(0,0,0,0)`、`(0,0,0,0)`；未覆盖像素保持 receiver 值。
- `Decal.channelMask` 5 位：albedo `1`、normal `2`、metallic `4`、AO `8`、roughness `16`；默认 `31`。sidecar 字段 `channelMask`。
- `Decal.layerMask` 7 位，默认 `0x7f`；receiver 使用 `RenderObject.decalLayerMask`（sidecar `objects[].decalLayerMask`），经 `u_object_lightLayerMask.y` 传入 GBuffer，`hbgApplyDecals` 按交集过滤。
- Decal layer v1 限制：DBuffer 每个像素只保留最后一个 decal 的 layerMask；同一像素多个不同 layer 的 decal 不能各自独立过滤。完整 HDRP cluster/layer 路径留给后续。
- GBuffer 增加 **第 5 个 MRT** `gbuffer.advanced`（`RGBA32F`），每通道 3×8-bit 精确打包 12 个材质量（clearcoat/normal、transmission/thickness/SSS、aniso/rotation/ior、iridescence/thickness）；现有 4RT 不变。`deferred diagnostics` 现为 `GBuffer MRT=5`。
- 验证（1280/640，D3D11/Vulkan）：
  - 无 decals baseline D3D/VK **0 diff**。
  - `m27_decals` decals on/off：**23.78 dB / 6,778 px / max 227**。
  - 4RT decals on 1280×720 D3D/VK：**0 diff**（640×360 为 100.51 dB/4 px）。
  - `channelMask=1`（仅 albedo）相对完整 channel mask：**24.30 dB / 6,399 px**。
  - receiver layerMask 与 decal layer 不相交：与 decals off **0 diff**。
- 文件：`decal.fs.sc`、`decal_clear.fs.sc`、`lighting/decal.sc`、`forward_renderer.cpp`（4RT/5RT、layer 绑定）、`scene/decal.h`、`scene/render_object.h`、`scene_loader.cpp`、`gbuffer.fs.sc`、`material_gbuffer.sc`。

## A02：材质数据/GBuffer 包（数据层、deferred/forward/area advanced v1、29 Lit variants v1 已完成）

已完成：

- `asset::Material` 新增 clearCoat/clearCoatRoughness/clearCoatNormalScale、transmission/thickness、ior、iridescence/ior/thickness、anisotropy/rotation、subsurfaceMask；`MaterialKey`/hash 同步。
- glTF 读取 KHR clearcoat/transmission/ior/iridescence/anisotropy/diffuse-transmission 因子；sidecar `hdrp` 或 `materials[]` 支持同名数值覆盖和 `features.subsurfaceScattering`。
- `material.idl` 新增 `advanced0/1/2`，MaterialUniforms 从 48B 扩为 **96B**；`material_system.cpp` 上传。
- GBuffer 5RT 的 advanced 包与解码函数已落：`surface_data_advanced.sc`、`material_gbuffer.sc`；forward/deferred 的 `SurfaceData` 高级字段由 `HBG_ADVANCED_MATERIAL` 门控，base 路径不改变。
- `hbgApplyAdvancedMaterial` 注入 tangent/clear coat/transmission/SSS/anisotropy/iridescence 参数。

已完成 advanced shading：

- **advanced deferred v1**：新增 `DeferredLightingAdvanced` program；stage 12 改绑 `gbuffer4`，其他 stage 不变；directional PCSS 在 advanced variant 回退为 tent7（t12 被 gbuffer4 占用），point/area PCSS 保留。无 advanced 材质时仍走原 deferred，M11/M12 基线 0 diff。
- clear coat 第二 specular lobe、SSS/transmission 传输项、anisotropic GGX、iridescence、iridescence F0 已在 `direct_lighting_advanced.sc` 和 `brdf_advanced.sc` 实现；GBuffer4 用 3×8-bit/float 精确打包 12 个字段（clearcoat/normal scale、transmission/thickness/SSS、aniso/rotation/ior、iridescence/thickness）。
- **advanced forward v1**：新增 `ForwardAdvanced` 与 `shaders/passes/forward_advanced.fs.sc`；按材质选择 no-map/map、single-sided/double-sided 四个 fragment 变体（buffer/non-buffer 各一套）。no-map 变体避免在无 UV/tangent 的 fallback normal 上采样，避免地板法线错误；map 变体保留正常/掩码贴图路径。HDRP 参考 `Lit.hlsl:433-488` 的 surface/BSDF 分支，以及 `LitForwardPass` 的 forward lighting 组织。
- advanced frame 禁用 forward instanced batch，回退逐物体 forward，避免把 advanced material 送进 instanced standard program；transparent/forward-only 仍走原路径。
- **area light advanced v1**：rectangle/tube 的 diffuse/specular LTC 保留，iridescence F0、clearcoat 第二 LTC lobe、transmission 反向/背面项和 SSS 近似已在 `hbgEvaluateAreaLightData` 生效；area shadow 仍最后应用。HDRP 参考 `Lit.hlsl:1559-1740` 的 `EvaluateBSDF_Area`。

剩余：

- **29 个 HDRP Lit variants v1 已生成**：新增 `deferred_lighting_variant.fs.sc` 和 `PassId::DeferredLightingVariant`，按 HDRP `kFeatureVariantFlags` 适配出 29 个表项；变体在 GBuffer 写入 per-pixel stencil（ref=`1+2*variant`），deferred 用 29 个 stencil-tested fullscreen draw 分派。
- 29 个变体在 SPIR-V 与 DXBC 均已编译 texture/buffer 两套；D3D11 的 58 个 raster dxbc 与 29 个 compute dxbc 已生成。`--lit-variants` 不再回退，D3D11 320x180 对 `--no-lit-variants` 的 coatonly/anisoonly/sssonly/stdarea/stdscene/advscene/advall 为 **0 diff**，iridonly **100.51 dB / max 1**。
- 变体表保留 material standard/ANY_SSS/anisotropy/clearcoat/iridescence 与 directional/punctual/area/shadow 组合；多特征无精确表项时走 variant 28 runtime catchall。
- HDRP 原实现是 `materialflags.compute` + tile feature flags + `builddispatchindirect.compute` 的 per-tile indirect dispatch；当前 v1 是 per-pixel stencil 分派，light feature flags 为 view-wide，tile 级分类/indirect dispatch 仍作为后续优化，不是最终 HDRP 性能路径。
- 验证：Vulkan 320×180，advscene（全特性）、coatonly、iridonly、anisoonly、sssonly、stdarea 的 29 variants on/off 均 **0 diff**；variants 分别为 28/20/25/15/10/4。
- 29 variants 使用 m_usedLitVariantMask 跳过本帧未使用的变体；全特性场景只提交 variant 28，避免 29 次无效 fullscreen draw。
- 29 variant 默认关闭：`supportLitVariants=false`，`--lit-variants` 开启；避免改变 M2–M12 默认 deferred 画面与性能基线。


- **Per-tile 29 variants v1（Vulkan/D3D11）**：参考 HDRP `materialflags.compute:1-70`、`builddispatchindirect.compute:1-58`、`Deferred.compute:106-165`。新增 `Lit Tile Feature Flags`（16x16 tile、64 threads、R32_UINT）、`Lit Variant Indirect Clear`、`Lit Variant Indirect`、`Deferred Lighting Compute`；tile list 追加在现有 FPTL buffer 的 `fptlCount` 之后，indirect args 为 29 个 32-byte record；compute 使用 8x8 group、每 tile 4 group，按 variant 做 `dispatchIndirect`，输出 RGBA16F scene color UAV（stage 14），SSAO 采样 stage 15；`s_cookieAtlas` 在 compute 中移到 stage 11；GBuffer4.w 写入 deferred coverage marker（standard=1，advanced=feature*65536），material flags 只分类 marker>0.5 的像素；SSAO 与 forward-only opaque 已支持。
- tile 路径开关为 `--lit-variants-tile` / `--no-lit-variants-tile`；pipeline 字段 `supportLitVariantTiles` 默认 false；启用时强制 scene color 为 **RGBA16F**（UAV 限制），并使用 GPU light-list **buffer** 路径。Vulkan 320x180：stdscene（standard）**100.51 dB / max 1**；advscene（advanced variant 28）**94.49 dB / max 1**；advall（advanced）**100.51 dB / max 1**；coatonly/iridonly/anisoonly **0 diff**；sssonly **97.50 dB / max 1**；stdarea **100.51 dB / max 1**。
- SSAO v1：tile compute 在 `u_ssao_params2.w > 0.5` 时用 `texture2DLod(s_ssao, depthUV, 0.0).r` 乘 `surfaceData.ambientOcclusion`；SSAO 采样放 stage 15，scene color UAV 放 stage 14，避免 stage 15 的 sampler/image 绑定冲突。D3D11/Vulkan stdscene+SSAO tile vs raster **100.51 dB / max 1**。参考 HDRP Runtime/Material/MaterialEvaluation.hlsl:40-57 的 1 - LOAD_TEXTURE2D(_AmbientOcclusionTexture) 与 deferred LightLoop 的 indirect 应用顺序。
- tile compute 的 dispatch mask 为 `m_usedLitVariantMask`（不再无条件加 variant28）；每个 variant 的 indirect X 从 1 开始，空 variant 用 1 个 dummy group，tile list 区域先写 `0xffffffff` sentinel，避免 Vulkan 0-group dispatch；`m_usedLitVariantMask` 的 raster 跳过逻辑不复用到 tile 路径。
- D3D11 tile compute dxbc 已编译；D3D11 320x180 per-tile 对 raster variants：stdscene/stdarea **100.51 dB / max 1**，sssonly **97.50 dB / max 1**，coatonly/iridonly/anisoonly **0 diff**；带 SSAO 的 stdscene **100.51 dB / max 1**。D3D11 对 advanced 材质走 raster fallback（variant 28 no-opt compute 1080p 仅 11.4 fps，fallback 约 113.5 fps）；标准场景 1080p 120 帧 tile 三次 107.0–125.3 fps（另有 141.6 冷启动样本）、SSAO 139.0 fps（单次）。默认 `supportLitVariantTiles=false`。
- HDRP 的 `materialflags.compute:53-58` 通过 stencil deferred bit 排除 forward-only；本项目不读 stencil，而用 GBuffer4.w coverage marker 让 material flags 跳过无 deferred 像素；混合 tile 中的 forward-only 像素仍可能被 compute 覆盖，随后 `Forward Only Opaque` 用 depth-equal 重写最终颜色。D3D11/Vulkan `m22_unlit_pair` tile vs raster **0 diff**；这是 v1 取舍，不应声称为完整 HDRP per-tile 架构。

## 当前阻塞 / 风险

- **D3D forward shader 缓存已收口**：DXBC `forward.fs.0..15` / `forward_buffer.fs.0..15` 已按各自 mask 重新编译，不再使用 variant 11 占位；D3D11/Vulkan `stdscene` forward 320x180 为 **0 diff**。FXC 对含 area lighting 的 D3D shader 在优化档会长时间不返回，构建脚本对这些 shader 走 `D3DCOMPILE_SKIP_OPTIMIZATION`（不传 `-O`，且该路径不启用 `--Werror`）。
- D3D advanced deferred / variant compute 的 FXC 优化会长时间不返回；`tools/shader_build.py` 对 forward、monolithic deferred、29 raster variants、29 compute variants 使用 skip-optimization 编译，单 shader 约 3–30 秒。该模式不启用 `--Werror`；优化档下 FXC 的保守 uninitialized-local 警告在 no-opt 路径下会重新出现，但不影响 DXBC 生成。
- advanced deferred 用 stage 12 读 gbuffer4，因此该路径下 directional PCSS 回退 tent7；无 advanced 材质的默认路径仍保留完整 PCSS。
- Decal layer v1 只保留最后 decal 的 layerMask；多 layer 共存需 HDRP cluster/layer 方案。
