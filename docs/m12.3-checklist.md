## A03：4RT DBuffer、per-channel mask、decal layers、额外 MRT（完成 v1）

- DBuffer 从 3RT 扩为 **4RT RGBA8**：
  - `decal0 = (albedo.rgb, albedoCoverage)`
  - `decal1 = (encodedNormal, normalCoverage)`
  - `decal2 = (metallic, AO, roughness, aoCoverage)`
  - `decal3 = (metallicCoverage, roughnessCoverage, layerMask/255, 0)`
- clear 值为 `(0,0,0,0)`、`(0.5,0.5,0.5,0)`、`(0,0,0,0)`、`(0,0,0,0)`；未覆盖像素保持 receiver 值。
- `Decal.channelMask` 5 位：albedo `1`、normal `2`、metallic `4`、AO `8`、roughness `16`；默认 `31`。sidecar 字段 `channelMask`。
- `Decal.layerMask` 7 位，默认 `0x7f`；receiver 使用 `RenderObject.decalLayerMask`（sidecar `objects[].decalLayerMask`），经 `u_object_lightLayerMask.y` 传入 GBuffer，`hbgApplyDecals` 按交集过滤。
- Decal layer v1 限制：DBuffer 每个像素只保留最后一个 decal 的 layerMask；同一像素多个不同 layer 的 decal 不能各自独立过滤。完整 HDRP cluster/layer 路径留给后续。
- GBuffer 增加 **第 5 个 MRT** `gbuffer.advanced`（`RGBA32F`），每通道 3×8-bit 精确打包 12 个材质量（clearcoat/normal、transmission/thickness/SSS、aniso/rotation/ior、iridescence/thickness）；现有 4RT 不变。`deferred diagnostics` 现为 `GBuffer MRT=5`。
- 验证（1280/640，D3D11/Vulkan）：
  - 无 decals baseline D3D/VK **0 diff**。
  - `m27_decals` decals on/off：**23.78 dB / 6,778 px / max 227**。
  - 4RT decals on 1280×720 D3D/VK：**0 diff**（640×360 为 100.51 dB/4 px）。
  - `channelMask=1`（仅 albedo）相对完整 channel mask：**24.30 dB / 6,399 px**。
  - receiver layerMask 与 decal layer 不相交：与 decals off **0 diff**。
- 文件：`decal.fs.sc`、`decal_clear.fs.sc`、`lighting/decal.sc`、`forward_renderer.cpp`（4RT/5RT、layer 绑定）、`scene/decal.h`、`scene/render_object.h`、`scene_loader.cpp`、`gbuffer.fs.sc`、`material_gbuffer.sc`。

## A02：材质数据/GBuffer 包（数据层完成，deferred shading v1 已完成）

已完成：

- `asset::Material` 新增 clearCoat/clearCoatRoughness/clearCoatNormalScale、transmission/thickness、ior、iridescence/ior/thickness、anisotropy/rotation、subsurfaceMask；`MaterialKey`/hash 同步。
- glTF 读取 KHR clearcoat/transmission/ior/iridescence/anisotropy/diffuse-transmission 因子；sidecar `hdrp` 或 `materials[]` 支持同名数值覆盖和 `features.subsurfaceScattering`。
- `material.idl` 新增 `advanced0/1/2`，MaterialUniforms 从 48B 扩为 **96B**；`material_system.cpp` 上传。
- GBuffer 5RT 的 advanced 包与解码函数已落：`surface_data_advanced.sc`、`material_gbuffer.sc`；forward/deferred 的 `SurfaceData` 高级字段由 `HBG_ADVANCED_MATERIAL` 门控，base 路径不改变。
- `hbgApplyAdvancedMaterial` 注入 tangent/clear coat/transmission/SSS/anisotropy/iridescence 参数，供后续 lighting 使用。

尚未完成：

- **advanced deferred 已接通 v1**：新增 `DeferredLightingAdvanced` program；stage 12 改绑 `gbuffer4`，其他 stage 不变；directional PCSS 在 advanced variant 回退为 tent7（t12 被 gbuffer4 占用），point/area PCSS 保留。无 advanced 材质时仍走原 deferred，M11/M12 基线 0 diff。
- clear coat 第二 specular lobe、SSS/transmission 传输项、anisotropic GGX、iridescence、iridescence F0 已在 `direct_lighting_advanced.sc` 和 `brdf_advanced.sc` 实现；GBuffer4 用 3×8-bit/float 精确打包 12 个字段（clearcoat/normal scale、transmission/thickness/SSS、aniso/rotation/ior、iridescence/thickness）。
- **forward advanced lighting 未启用**。base forward 仍走标准材质；当前 29 个 forward variants 的编译预算不允许直接铺开。
- **29 个 HDRP Lit variants 未生成**。当前架构是 full-screen deferred + runtime light feature flags，HDRP 的 29 个 `kFeatureVariantFlags` 是 per-tile variant 选择，需要 HDRP 式 tile variant dispatch；不能在 full-screen pass 里伪造成 29 个同代码变体。把该工作留到 per-tile classification 阶段。
- area light 的 advanced BSDF 尚未接入（area LTC 仍走 base 路径）。

## 当前阻塞 / 风险

- **D3D forward shader 缓存风险**：本机 shaderc O3 编译单个 forward 变体约 9 分钟；本轮为解除构建阻塞，DXBC `forward.fs.0..10` / `forward_buffer.fs.0..10` 曾被缓存占位。**这些不是最终验收 shader**，下一步必须在可稳定编译的环境重建；当前默认 deferred 路径和 Vulkan 路径不受影响。
- D3D advanced deferred 单变体约 **10–12 分钟**；`tools/shader_build.py` 默认 timeout 已从 600s 提高到 **1800s**，否则 C++ 构建会在 shader target 超时。
- advanced deferred 用 stage 12 读 gbuffer4，因此该路径下 directional PCSS 回退 tent7；无 advanced 材质的默认路径仍保留完整 PCSS。
- Decal layer v1 只保留最后 decal 的 layerMask；多 layer 共存需 HDRP cluster/layer 方案。
